# CLAUDE.md

## Tech Stack

- Plain HTML, CSS, and JavaScript only.
- No frameworks or libraries (no React, Vue, Tailwind, jQuery, etc.).
- No build step: files are opened or served exactly as written.

## Project Structure

The repository is nearly empty for now. Keep files at the top level until
there is a reason to organise them:

- `CLAUDE.md` – these instructions.
- `index.html` – the main page (to be added).
- `styles.css` – shared styles (to be added).
- `script.js` – shared JavaScript (to be added).

## Key Requirements

1. Every page must be responsive and work on desktop, tablet and phone.
2. Users can toggle between a light and a dark theme. The default is the
   light theme.
3. Text must stay easy to read, with good contrast, in both the light and
   the dark theme.
